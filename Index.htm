Concept 1

What is a Conditional Statement?

Computers use conditions to make decisions based on rules.

if - then

One Pathway Choice

Runs the code inside ONLY IF the condition is TRUE. If FALSE, Scratch skips it entirely.

if <touching lava?> then
  lose life
if - then - else

Two Pathway Choice

Has two branches: runs path #1 if TRUE, or switches to path #2 if FALSE!

if <score > 10> then
  say "You Win!"
else
  say "Keep Trying!"
Teacher Tip: Remind students that conditions always result in either TRUE or FALSE.
Quiz Breakdown

Understanding Decision Logic

Question 6

What happens if a condition inside an if-then block is FALSE?

Answer: Scratch skips the code inside and moves directly to the next block.
Question 8

What is the main difference between if-then and if-then-else?

Answer: if-then-else provides two distinct pathways (one for TRUE and one for FALSE).
